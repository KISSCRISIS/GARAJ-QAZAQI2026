# 05 guard.html — Guard Operation Screen (light)

## Purpose

Fast guard operation. Camera + result + security message.

## Flow

Guard Login (Access Code + Device check) → Camera Ready → Scan QR → Result.

REJECTED fields: Date Of Birth, Age, Residence (privacy; conflicts with open-screen principle).

## Allowed

Photo, name, job, department, permission status.

## Denied

Denied + reason only.

## Restrictions

Guard cannot: search employees, edit data, open profiles, view full logs, open Dashboard. No Dashboard inside Guard.
